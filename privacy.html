Shadow Player 개인정보처리방침

시행일: 2026년 11월 15일

Shadow Player(이하 "앱")는 사용자가 듣는 노래에서 좋아하는 구간을 저장하고 반복해 들을 수 있게 해 주는 앱이에요. 앱은 회원 가입이나 로그인이 없고, 개발자가 운영하는 서버로 사용자의 개인정보를 보내지 않아요. 이 방침은 앱이 어떤 정보를 어디에서, 왜 다루는지 설명해요.

1. 휴대폰 안에서만 다루는 정보

아래 정보는 사용자의 휴대폰 안에서만 쓰이고, 개발자에게 전송되지 않아요.

  • 저장한 구간과 메모: 곡 제목, 아티스트, 구간 시작·끝 시간, 사용자가 적은 메모. 앱을 지우면 함께 지워져요.
  • 재생 중인 곡 정보 (알림 접근 권한): YouTube Music · Spotify · 멜론에서 재생 중인 곡의 제목, 아티스트, 재생 위치를 읽어 화면에 보여 주고 구간 반복에 써요. 알림 내용 자체는 읽거나 저장하지 않아요.
  • 휴대폰 음악 파일 (음악 접근 권한): 사용자가 고른 폴더의 음악 파일을 목록에 보여 주고 재생해요.
  • 소리 크기 (녹음 권한): '자동볼륨'을 켜면 재생 중인 소리의 크기만 측정해 볼륨을 맞춰요. 마이크로 녹음하지 않고, 소리를 저장하거나 전송하지 않아요.
  • 다른 앱 위에 표시 권한: 저장 구간에서 다른 음악 앱의 곡을 이어서 열 때 써요. 화면 내용을 읽지 않아요.

2. 사용자가 직접 보낼 때만 나가는 정보

  • 카카오톡 공유: 사용자가 '카톡 보내기'를 누르면, 공유 카드 이미지와 곡 정보(제목, 아티스트, 구간 시간, 메모)가 카카오의 공유 서비스를 통해 전달돼요. 이 과정에는 카카오의 개인정보처리방침이 적용돼요.
  • 이미지로 보내기: 사용자가 고른 앱으로 카드 이미지와 링크가 전달돼요.
  • 공유 페이지: 받은 사람이 링크를 열면 GitHub Pages에 있는 공유 페이지가 열리고, 그 안에서 YouTube 플레이어로 구간을 들을 수 있어요. 이때 YouTube(Google)의 정책이 적용돼요.
  • 백업 파일: 설정 › 백업으로 만든 파일은 사용자가 고른 곳에만 저장돼요.

3. 자동으로 수집되는 정보

  • 오류 진단 정보: 앱이 비정상 종료되면 오류 위치, 기기 모델, 안드로이드 버전, 앱 버전 같은 진단 정보가 Google Firebase Crashlytics로 전송돼요. 앱 품질을 고치는 데만 쓰이고, 이름·연락처 같은 개인 정보는 포함되지 않아요.
  • 앨범 이미지: 곡 표지를 보여 주려고 YouTube 이미지 서버(i.ytimg.com)에서 이미지를 받아 와요.

4. 제3자 제공과 보관

앱은 위에 적은 경우 말고는 정보를 제3자에게 팔거나 제공하지 않아요. 휴대폰 안의 정보는 앱을 지우면 사라지고, 오류 진단 정보는 Firebase의 보관 기간(최대 90일)에 따라 지워져요.

5. 사용자의 선택

  • 알림 접근, 음악 접근, 녹음, 다른 앱 위에 표시 권한은 휴대폰 설정에서 언제든 끌 수 있어요. 끄면 그 기능만 쓸 수 없어요.
  • 저장한 구간은 앱에서 언제든 지울 수 있어요.

6. 어린이

앱은 어린이를 대상으로 만들지 않았고, 어린이의 개인정보를 알면서 수집하지 않아요.

Summary in English

  • No accounts. The developer runs no server and receives no personal data.
  • Saved parts, memos and the current song's details (read through notification access from YouTube Music, Spotify and Melon) stay on the device.
  • The microphone permission is used only to measure playback loudness for auto volume; nothing is recorded, stored or sent.
  • KakaoTalk sharing, image sharing and the share page (GitHub Pages, with the YouTube player) send data only when the user shares.
  • Crash diagnostics (device model, Android and app version, stack trace) go to Google Firebase Crashlytics.
